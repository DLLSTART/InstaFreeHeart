| —  | 续航 10–12 h（高强度模式） | 高效 buck + Light Sleep 调度 | 4000 mAh + η=92% |

## 4. 设计选型决策记录

| 决策点 | 选择 | 原因 |
|-------|------|------|
| 主控 | ESP32-S3-WROOM-1-N16R8 | 单芯片整合 WiFi/BT/AI 加速，DVP+I²S 同时可用，固件生态成熟（esp-camera / esp-dl） |
| 摄像头 | OV5640 (DVP, 5MP) | 500W 像素 + 硬件 line-interleaved HDR，esp32-camera 已支持，夜景日记关键 |
| 麦克风 | INMP441 ×2 | I²S 数字接口免 ADC；双麦立体声差分降噪 + 防风罩 |
| 充电管理 | IP5306 | 集成充电+升压+LED 指示+按键检测，BOM 极简 |
| 电量计 | CW2015 | 精度优于分压方案，国产成本低，I²C |
| 3V3 主电源 | SY8088 Buck (1.5 MHz) | 直接 BAT→3V3，η=92%（vs LDO 路径 56%），续航 +66% |
| 电池保护 | DW01A + 8205A | 国产标配方案，过充/过放/过流/短路全保护 |
| 灯环 | WS2812B-2020 ×16 | 单线通信节省 IO，2020 封装紧凑适合环形排布 |
| 电池 | 2× 3.7V 2000 mAh 软包并联 | 总 4000 mAh / 14.8 Wh，厚 7 mm 可装入 15 mm 整机厚度 |
| 接口 | USB-C | 双向 5V，正反插，统一现代接口 |
| 散热温控 | ADS1115 + 3 NTC | 不占 GPIO；4 通道 16-bit 精度足够 |
| 散热增强 | 25 µm 石墨烯膜 + 0.5 mm TIM | 横向均温（k=1500） + 纵向导热到后壳 |
