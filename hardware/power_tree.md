# InstaFreeHeart 电源拓扑（双电池并联 · Buck 直供 3V3）

> 详见功耗预算：[`mechanical/power_budget.md`](../mechanical/power_budget.md)

## 1. 电源树（双路供电）

```
                ┌───────────────────────┐
   USB-C (5V) ──┤ VBUS         IP5306   │
                │  (输入 1A 充电)         │
                │                        │
                │  BAT  ◄───── 4.2V CC/CV│
                └─────┬───────────┬─────┘
                      │           │
              ┌───────▼─────┐     │ KEY
              │ 锂电保护板    │     │ (按键检测/工作灯)
              │ DW01A+8205A │     │
              └───────┬─────┘     │
                      │           │
              ┌───────▼─────┐     │
              │  电池 1S2P   │     │
              │ 2× 2000 mAh │     │
              │ = 4000 mAh   │     │
              └─┬───────┬───┘     │
                │       │         │
                │       │  ┌──────▼─────────┐
                │       ├──┤ IP5306 BOOST 5V│──── VOUT_5V ──── USB-C(对外，给手机充)
                │       │  └────────┬───────┘                  │
                │       │           │                          └─→ WS2812B 灯环 (NMOS 切)
                │       │           │
                │       │  *5V 仅在充手机/驱动 5V 灯环时使用，平时 IP5306 静态 1.85 mW*
                │       │
                │       │   ┌────────────────────────┐
                │       └───┤   SY8088 Buck          │──   3.3V ── ESP32-S3 / OV5640 /
                │           │   3.7V → 3.3V/1A       │             INMP441 ×2 / TF / CW2015 /
                │           │   1.5 MHz, η=92%       │             ADS1115
                │           │   2.7~6.5V 输入        │
                │           └────────────────────────┘
                │
                └─── CW2015 (BAT+) ── I²C(SDA/SCL) → ESP32
                          电量计 / SoC 估计 + 库仑积分

3V3 由 BAT 直接通过 Buck 供电（η=92%）；IP5306 仅在 USB-C 充电或对外输出 5V 时启用升压。
```

## 2. 电源域汇总

| 电源域 | 电压 | 来源 | 典型电流 | 峰值电流 | 关断方式 |
|--------|------|------|---------|---------|---------|
| VBUS   | 5 V  | USB-C 输入 | 0~1.5 A | 2 A | USB 拔出 |
| BAT    | 3.0~4.2 V | 锂电芯 1S2P (4000 mAh) | — | 充 1.5A / 放 3 A | DW01A 触发 |
| VOUT_5V | 5 V | IP5306 升压（仅充手机/灯环时启用） | 0~1 A | 2.1 A | IP5306 KEY 双击 |
| VSYS_3V3 | 3.3 V | SY8088 Buck (从 BAT 直供) | 150 mA (含摄像头) | 600 mA | EN=GND |
| VCAM   | 2.8 V (内部) | OV5640 内部 LDO | 100 mA | 150 mA | OV5640 PWDN |

## 3. 关键电源元件计算

### 3.1 IP5306 升压电感
- 输入：BAT 3.7 V，输出 5 V/1 A，效率 ≈ 90%。
- 推荐 2.2 µH，饱和电流 ≥ 3 A，DCR ≤ 30 mΩ。

### 3.2 SY8088 Buck 外围
- **L_BUCK** = 2.2 µH @ Isat ≥ 2 A，DCR ≤ 50 mΩ（如 SLW2520 系列）
- **C_in**  = 22 µF / 6.3V 0805 MLCC，紧贴 VIN 引脚
- **C_out** = 10 µF / 6.3V 0805 MLCC，紧贴 VOUT
- **R_FB1** = 1 MΩ（FB 上拉），**R_FB2** = 220 kΩ（FB 下拉）→ V_out = 3.32 V
- **占板面积**：约 4×3 mm（含 SOT-23-5 + L + C_in + C_out + 2× 0402 R）

### 3.3 摄像头瞬态
- OV5640 进入工作时电流瞬升 100→150 mA，3.3V 轨需 ≥10 µF 局部去耦放在距离 OV5640 5 mm 内。
- SY8088 在 1.5 MHz 开关频率下瞬态响应 < 50 µs，无需额外大电容。

### 3.4 灯环峰值电流
- WS2812B-2020 单颗满白 ≈ 30 mA；16 颗满白 ≈ 480 mA。
- 经 NMOS 开关从 VOUT_5V 取电；软件层面限亮度（默认 30%）使峰值 ≤ 200 mA。

## 4. 锂电池保护板（DW01A + 8205A）

```
    BAT_CELL+ ──┬─────────────────────── B+ (BAT 引出，进 IP5306)
                │
              ┌─▼─┐
              │   │  DW01A
              │ V │   - VDD: BAT_CELL+
              │ D │   - VSS: BAT_CELL-（电池负极）
              │ D │   - VM:  保护板 P-，监测 P- 端电压
              │   │   - OD:  放电控制 → 8205A G1
              │ V │   - OC:  充电控制 → 8205A G2
              │ M │   - TD:  延时电容（0.1µF 到 GND）
              └─┬─┘
                │
            8205A 双 NMOS（DPAK SOT-23-6）
            ┌─────────────┐
            │  D1 D2      │ ← 漏极并联
            │  G1     G2  │ ← 分别由 DW01A OD/OC 驱动
            │  S1     S2  │ ← 串联在电池负极回路
            └──┬───────┬──┘
               │       │
       BAT_CELL-       P-（板对外的 BAT- 节点）
                       │
                   连接 IP5306 GND / 系统 GND
```

保护阈值（DW01A 默认）：
- 过充电压：4.30 V ± 0.05 V
- 过放电压：2.40 V ± 0.10 V
- 过流保护：电流·内阻 > 0.15 V 触发（约 3 A 起跳）
- 短路保护：< 10 µs 切断

> 双电池并联时，两颗电池正极、负极分别先短接，再共同接保护板的
> CELL+/CELL−，由 DW01A 监控总组电压（不做 cell-balancing，因为同型号同批次
> 的并联电池容量自然均衡，无 cell-imbalance 风险）。

## 5. 充放策略

| 状态 | IP5306 行为 | ESP32 行为 |
|------|------------|------------|
| 仅插 USB-C，未接负载 | 给电池充电 | 正常工作，灯环显示充电进度（呼吸） |
| 插 USB-C + 接手机 | 给电池充电 + 给手机供电（旁路） | 正常工作，灯环显示满环 |
| 拔 USB-C，接手机 | 电池经 BOOST 给手机供电 | 正常工作 + 监控 SoC，<10% 时关断输出 |
| 仅电池供电，无外设 | 待机 / 30 s 后自动关断 BOOST | 软件唤醒 IP5306 KEY 拉低重启 |
| SoC < 5% | 强制关断 BOOST | 软件保存 NVRAM 后深度睡眠 |
